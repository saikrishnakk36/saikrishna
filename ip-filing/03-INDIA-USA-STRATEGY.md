# Dual-Jurisdiction Filing Strategy — India + USA (HRoT, NoC)

Avecas has entities in both India and the US. Inventors are India-resident, so the
invention is "made in India" → **India-first filing is mandatory** (Patents Act §39);
the US entity can still be the owner/applicant.

## Hard rule: file India first, then go abroad

- Inventors sit in Hyderabad → §39 requires either **filing in India first** OR obtaining a
  **Foreign Filing License (FFL)** before any foreign filing. Violation is a criminal offense
  and can void the Indian patent.
- **Do NOT file in the US first.** File the Indian provisional, then clear FFL (wait 6 weeks
  after Indian filing, or request the FFL), then file abroad.
- US company as *applicant/owner* is fine and separate from where the invention was made.

## Recommended route: India provisional → PCT → national phase (US + India)

| Month | Step | Rough cost / core |
|---|---|---|
| 0 | File **Indian provisional** (Form 1 + 2 + 3 + 26 + 28 startup) | ~₹1,600 |
| 0–1.5 | **FFL clears** (6-week wait or FFL request) — foreign filing now allowed | — |
| ~12 | File **PCT application** claiming the India priority date | ~₹1.3–1.7L (fees + agent) |
| ~12 | File **Indian complete specification** (Form 2) | included in agent fee |
| ~18 | PCT publishes; **International Search Report** guides claim strategy | — |
| 30/31 | **National phase entry: USA + India** (+ UK / Malaysia optional) | US ~$10–15k; India ~₹8k + agent |

**Why PCT, not direct Paris-route filings:** defers the big US spend to month 30/31 and gives
the ISR at ~month 18 — you learn whether the claims are strong before committing US money.
Right trade-off for a startup building a portfolio and keeping UK/MY options open.

**Alternative (only if US speed-to-grant drives a deal):** skip PCT, file a **direct US
non-provisional at month 12** under the Paris Convention alongside the Indian complete spec.

## US-side specifics

- **Entity size:** USPTO **small entity = <500 employees** → Avecas (100+) qualifies → ~60% fee cut.
  **Micro entity** (75% off) needs ≤4 prior US apps + a gross-income cap — likely does NOT apply;
  file as **small entity**.
- **Cost / core (US):** filing/search/exam ~$1,500–2,000 (small entity) + attorney **$12–18k** over life.
- **§101 / Alice (US analog of §3(k)):** HRoT and NoC are hardware → safe. Claim as **hardware
  systems/circuits with a concrete technical improvement** (latency, power, area, security). Never method-only.
- **Grace period:** US gives 1 year for the inventor's own disclosure; **India gives none** → the
  binding constraint is India. File the Indian provisional **before any further public disclosure**.

## Ownership decision (resolve before assignment)

- Choose owner: **Avecas India vs Avecas US (Delaware?)**. Affects licensing, royalty withholding
  tax (India–US treaty), and transfer pricing if the US entity licenses the IP out.
- US ownership is often cleaner for US-market licensing and enterprise contracts — but **confirm with
  a cross-border tax advisor before assigning**; moving IP between entities later is expensive.
- Inventors assign to whichever entity; the §39 FFL obligation is unchanged either way.

## Firm setup

Engage one **US patent attorney** (USPTO-registered) coordinating with an **Indian patent agent**
(or an Indian firm with a US associate). One consistent specification, filed India-first, carried
into PCT/US. Do not run two uncoordinated drafts.
